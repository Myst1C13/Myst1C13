### Some Things I've Built

**🤝 [Baton](https://github.com/Myst1C13/Baton)** — AI Agent Handoff Engine

At the **UC Berkeley AI Hackathon 2026**, I worked with a team on Baton, a tool that lets you hand off unfinished coding tasks between Claude Code and Codex without losing code changes, terminal context, or test results.

We used TypeScript, React, Electron, WebSockets, and Redis. In a six-scenario benchmark, we reduced serialized handoff context by about 88% while retaining the required evidence.

**💳 [Quickr](https://github.com/Myst1C13/Quickr)** — Quoting, Invoicing & Payments SaaS

Quickr started as a way to simplify the business side of independent contracting. It handles quotes, invoices, customer approvals, Stripe payments, subscriptions, and automated reminders.

The backend runs on Node.js with PostgreSQL, Supabase, Stripe, and Netlify Functions.

**🐳 [Self-Healing Docker](https://github.com/Myst1C13/Self-Healing-Docker)** — Container Reliability System

I wanted to explore how services can detect failures and recover without manual intervention. This project monitors Docker containers for unhealthy behavior, automatically handles recovery, and keeps track of incidents and recovery times.

It uses Python, FastAPI, Docker SDK, SQLite, and AWS services.
